Build a marketing website for Infincy, a small software engineering studio (currently a solo founder) that builds full-stack web applications, backend systems, cloud infrastructure, and AI/agentic features for businesses. Position it as an engineering studio that also does advanced AI work — NOT as an "AI startup." Avoid every visual cliché of AI-company websites: no gradient orbs, no purple-to-blue gradients, no glowing blobs, no robot/brain/neural-network illustrations, no generic "Empowering the future of intelligent solutions" copy. This should feel like a confident, crafted, human studio site — closer to a boutique design/dev studio than a SaaS dashboard.

Tech & structure
React + Tailwind CSS, fully responsive, clean semantic structure.
5 pages/routes: Home, About, Services, Work, Contact. Single consistent nav across all pages, single consistent footer with contact info and social/GitHub/LinkedIn links (use placeholder links I'll swap later).
One repeated call-to-action phrase throughout the site: "Start a project" — button in the nav, in the hero, and at the bottom of every page, linking to the Contact page.
Smooth, purposeful micro-interactions only: hover states on buttons/cards, a subtle fade/slide-in as sections enter the viewport on scroll, headline weight/size shifting slightly on scroll if feasible. Keep all animations fast and subtle (under ~300ms) — not flashy, not distracting.
Layout should feel slightly asymmetric and intentional — avoid the default centered-hero + 3-icon-cards template look. Vary section layouts (e.g. alternate left/right image-text splits, an uneven grid for case studies) rather than repeating one block pattern down the page.

Typography:

Headline/display font: Fraunces (Google Font, use bold/expressive weights, this is the personality of the site — headlines should be large and confident, sometimes oversized as a visual element in themselves).
Body font: Inter or General Sans (clean, quiet, readable — body text should not compete with headlines).
Strong type hierarchy: hero headline should be very large (think 56–80px desktop), section headers clearly smaller but still bold, body text comfortable and readable.

Imagery: No stock illustrations, no AI-generated abstract art, no robot/brain graphics. Use simple placeholder blocks/frames labeled clearly (e.g. "[screenshot of project here]") where real screenshots or photos will go later — I'll replace these myself.
